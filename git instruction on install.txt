First download git file from google on git-scm.com

Then next next next without changing anything in the installation window then uncheck both at last and finish the installation.

Right click in folder or repository which you use git and click open git-bash here.

--> Then type (git -v) to check version whether git is installed properly or not.

--> After installing git run these command to setup you user_name and email globally.
1- (git config --global user.name "name")
2- (git config --global user.email "email")
3- (git config --global core.editor "code --wait")  # optional, sets VS Code as editor

--> To check your configuration -: (git config --list)

--> To quit press -: q

--> Always use git status after every git command to see the status of the repository.

--> Git has three key areas:- ** Edit files → (git add .) → (git commit -m "comment") first comment should be "initial commit". **

1. Working Directory – Where you edit files. i.e the folder where you open git bash here.

2. Staging Area – Where you prepare files which are going to be committed. 

3. Repository – Where committed changes are stored permanently or it is a checkpoint.
 
--> (git init) --> means making that folder tracked by git as a repository.

--> It create a hidden folder in the same repository name .git where all the snapshots are saved by git.

--> (git add index.html assets/ about.html) or (git add .) for all files once to bring the files or folder to staged area.

--> (git status) to track and show the status of the repository. i.e which files or folders are modified, untracked, tracked, staged, committed etc.

--> (git log) all commits with details.
--> (git log --oneline) all commits in single line.

**NOTE** --> never run (git init) command inside cloned repository becoz it is already tracked by git the moment we cloned it.
--> (git clone url) --> it will clone the whole repository from github of anyone. make sure when cloning do in different folder outside of current repository folder.

-->Files in Git move through three main states: ** working Directory → git add → Staging Area → git commit → Repository  **

1. Untracked – not being tracked yet.

2. Staged – ready to be committed.

3. Committed – saved permanently in the Git history

--> (git restore file_name) to revert it back before any recent changes made.
--> (git restore --staged file_name) it is used to unstaged the file back which have been staged but it does not revert any changes made inside the content of the file.

--> (git diff) shows what changes have been made recently in files.
